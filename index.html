Credit Card Fraud Detection

A classifier trained to catch fraudulent transactions inside a highly imbalanced dataset — 284,807 real, anonymized transactions, only 492 of them fraudulent. Built end-to-end: data prep, class-imbalance handling, model comparison, and a live scoring tool.

02 — Input Format

What the model sees

Each row is a single transaction. V1–V28 are PCA-anonymized features (the original details are confidential); Time and Amount are the only two raw values retained. Class is the ground-truth label: 1 for fraud, 0 for legitimate.

03 — Approach

Two models, head to head

A 70/30 stratified split kept the same fraud rate in both sets. Time and Amount were standardized; the PCA columns were already scaled. Both models used class-weighting rather than naive oversampling, so the training itself compensates for the imbalance instead of duplicating rare fraud rows.

04 — Results

Why Random Forest wins

Random Forest is the practical choice: logistic regression catches slightly more fraud but at the cost of 1,806 false alarms on legitimate transactions — unusable for a real system. Random Forest catches 111 of 148 frauds in the test set while flagging only 18 legitimate transactions.
